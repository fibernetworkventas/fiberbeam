# fiberbeam

## Requisitos

- Node.js
- MongoDB

## Instalación

```bash
npm install
```

## Ejecución

```bash
node server.js
```

## Subir y listar archivos

1. Abre la interfaz HTML del proyecto en tu navegador.
2. Para subir un archivo, selecciona el archivo y pulsa **Upload**.
3. La página mostrará la lista de archivos cargados.
